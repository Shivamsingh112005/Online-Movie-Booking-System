# 🎬 Online Movie Booking System

## About the Project

The Online Movie Booking System is a web-based application designed to provide users with a simple and convenient way to browse movies, view movie details, register and log in, book movie tickets, and proceed through a payment interface.

## Features

- 🎬 Browse movies
- 🔐 User registration and login
- 🎟️ Movie ticket booking
- 💳 Payment interface
- 📱 Responsive design
- 🖥️ User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

| File | Description |
|---|---|
| `index.html` | Home page |
| `movie.html` | Movie details |
| `login.html` | User login |
| `register.html` | User registration |
| `booking.html` | Ticket booking |
| `payment.html` | Payment page |
| `style.css` | Website styling |
| `script.js` | JavaScript functionality |

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
